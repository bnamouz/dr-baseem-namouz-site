# One public website

Canonical website: https://magickidsinstitute.com/index.html

All HTML routes are generated by `node scripts/build-website.mjs` from one header, footer and page system. Edit that generator, `src/copy.mjs`, `src/translations.json`, `brand.css` and `app.js`; do not independently restyle generated pages.

Run `python scripts/verify-website.py` after rebuilding. It checks every local route, fragment, asset, three-language key and app icon. Arabic is rendered in the HTML by default; a chosen language is retained in local storage and propagated in internal navigation URLs, including when storage is unavailable. Page-specific metadata is translated too.

The `app.html` page installs the same website as a PWA. Browser support determines whether an install prompt or platform instructions are shown. The service worker never caches clinical data or API calls. Navigations use the network; offline access provides the public contact page only. Change the release label in both the builder and service worker when publishing shared-asset updates.

Public interest/application forms prepare email or WhatsApp drafts addressed to the institute. They do not save submissions or claim successful delivery. The existing private management app retains its own stored enquiry workflow. No website form is an appointment confirmation.

`site-config.js` holds public contact and optional Google booking/analytics configuration. Search Console verification is included during generation. No credentials belong in this repository. Online appointment booking remains disabled until a real clinic booking URL is configured. The private staff area links to the identified Pediatrics Clinic Appointments calendar; the connected account currently has reader access. Calendar events stay in Google, behind its access controls.

The old workshop date (19 April 2026) is historical; the page now accepts enquiries about a future session without advertising an unconfirmed date or price.
